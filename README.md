# Discrete Event / Rate Simulation Framework

Python framework for building and running:
- **DES** (Discrete-Event Simulation): event-driven process flow,
- **DRS tickwise**: rate/inventory updates at fixed discrete ticks,
- **DRS threshold-crossing**: sparse control events predicted from piecewise-constant dynamics.

---

## 1) Clone and setup

```bash
git clone <your-repo-url>
cd discrete-event-simulation
```

### Install dependencies

Preferred:

```bash
uv sync
```

Alternative:

```bash
pip install -e .
```

Python: **3.12+**

---

## 2) General idea

The project has a layered design:

1. **Core DES runtime** (`src/core`)
   - `Engine`, `Event`, component classes, queue/resource protocols.
2. **Modeling helpers** (`src/modules`)
   - operation modes, threshold-crossing tools, plotting/output utilities.
3. **Examples/simulations** (`src/simulations`)
   - runnable references from simple DES to advanced DRS/resource workflows.

Use the central runner:

```bash
python -m src.run --file <simulation.py>
```

Optional flags:
- `--viz` for PDF event-flow visualization
- `--plot` for simulation-defined plots (if implemented by that simulation)



## 6) Typical workflow

1. Copy an existing simulation from `src/simulations`.
2. Modify component logic/state.
3. Run with `python -m src.run --file <your_simulation.py>`.
4. Add `--viz` / `--plot` while tuning behavior.
5. Use `docs/OUTPUT_PLOTTING_DATA_PATTERNS.md` to improve output quality.
